# Conteo de palabras y frecuencia

Script que lee un archivo de texto, cuenta el total de palabras, la cantidad de caracteres y la frecuencia con la que se repite cada palabra utilizando el método de ordenamiento llamado `merge sort`

## Cómo ejecutarlo

1. descarga el repositorio `https://github.com/barrera1994/contar_palabras`
2. Abre una terminal y ejecuta el siguiente comando `py contar_palabras.py`

## archivo de texto

En la carpeta raíz se dejó el archivo texto_prueba.txt. Si deseas analizar un archivo diferente: modifica la línea 59 del script con el nombre o ruta del nuevo archivo:
```python
contar_palabras("texto_prueba.txt")
```
